# Roadmap

## Current Foundation

Linka is a lightweight, local-first trackpad controller.

Current foundation includes:

- macOS, Windows, and Linux input layers
- local pairing and session management
- trackpad, keyboard, scroll, and volume control from a phone browser
- bridge and context-transfer flows
- single-file mobile client

## Near-Term

Priority areas:

- polish packaging and reduce the size of the shipped app
- improve pairing and reconnection reliability
- smooth trackpad feel and latency on all platforms
- broader testing and platform validation (including Wayland)
- tighter security and permission documentation

## Long-Term

Long-term goals:

- deeper camera/phone features beyond the browser client
- better multi-monitor handling
- more reliable cross-platform input layers
- optional self-hosted fast relay only with explicit user opt-in

The long-term product question is whether Linka can be a dependable, low-friction way to control a computer from a phone — while staying small, local, and private.
