# Roadmap

## Current Foundation

Linka already provides a local desktop foundation that can support future agent-oriented workflows.

Current foundation includes:

- macOS, Windows, and Linux project direction
- local pairing and session management
- local desktop interaction
- bridge and context-transfer flows
- platform-specific desktop input layers
- Teach workflows where implemented today

Current reality to keep in mind:

- Teach is macOS-first
- human approval is a design goal, not yet a complete orchestration layer
- MCP and Codex Skill interoperability are future milestones, not current features

## Near-Term

Near-term work is about turning Linka from an interesting local runtime into a clearer agent-facing foundation.

Priority areas:

- MCP server design
- Codex Skill packaging research
- approval workflow model
- better cross-platform Teach support
- release packaging and distribution cleanup
- testing and validation across platforms
- clearer docs and example workflows

Additional near-term goals:

- tighten architecture and trust-boundary documentation
- improve platform-specific setup clarity
- publish examples that show review-first desktop workflows

## Long-Term

The long-term direction is to make Linka useful as a serious local runtime for human-supervised agents.

Long-term goals:

- reusable agent skills
- community-contributed workflows
- local desktop agent runtime
- accessibility-focused agent workflows
- safe human-supervised automation

The long-term product question is not whether Linka can send input events. The real question is whether it can become a trustworthy local execution layer for agent systems that still require human judgment.
